## 🌙 What is ProofPass?

ProofPass is a privacy-first credential verification dApp that lets students **prove they satisfy academic and skill-based eligibility requirements** for internships and jobs — without revealing their actual CGPA, project list, or any personal data.

Using Midnight Network's native ZK (Zero-Knowledge) proof capabilities, students submit a cryptographic proof. The smart contract verifies this proof on-chain. The recruiter sees **"Eligible ✅"** — not the student's actual marks.

---

## 🔒 Privacy Model

When a student calls `verify_eligibility`, they generate a Zero-Knowledge proof locally in their browser. The proof is submitted to Midnight Network.

### What an observer **CAN** see (public on-chain):
- ✅ That a verification was submitted and accepted
- ✅ Total number of verified students (the counter)
- ✅ An anonymous nullifier (prevents double-claiming)
- ✅ The eligibility thresholds set by the recruiter (CGPA ≥ X, Projects ≥ Y)

### What an observer **CANNOT** see:
- ❌ The student's actual CGPA
- ❌ The student's exact number of projects
- ❌ Whether the student has specific skills (only that the skill requirement was met)
- ❌ The student's identity, wallet address, or student ID
- ❌ Any private input to the ZK circuit

### Nullifier Anti-Replay
Each student is assigned a private `student_id`. This ID is hashed into an anonymous **nullifier** using `make_nullifier(student_id)`. The nullifier is inserted into a public on-chain set. If the same student tries to prove eligibility twice, the proof is rejected — without revealing who they are.

## 🏗️ Architecture

```
contracts/
  proofpass.compact        ← The ZK smart contract (write this)
  managed/proofpass/       ← AUTO-GENERATED by compact compiler (never edit)
  index.ts                 ← TypeScript entry point for Node.js tests

src/
  config.ts                ← Network configurations (local/preview/preprod)
  providers.ts             ← SDK provider factory for Node.js
  test/
    proofpass.test.ts      ← Vitest test suite (6 tests)

frontend/
  src/
    lib/midnight.ts        ← Core SDK utilities, session factory
    contexts/WalletContext.tsx
    pages/
      LandingPage.tsx      ← Privacy visualization + feature showcase
      StudentPage.tsx      ← ZK proof submission UI
      AdminPage.tsx        ← Contract deployment UI for recruiters
  public/managed/          ← ZK proving keys (served at /managed/)

scripts/
  wait-for-dust.ts         ← Waits for DUST tokens before tests

.github/workflows/ci.yaml  ← GitHub Actions CI/CD pipeline
compose.yml                ← Docker Compose for local network
```

## 📦 Setup

### Prerequisites

| Tool | Version | Install |
|------|---------|---------|
| Node.js | >= 22.0.0 | https://nodejs.org |
| Yarn | 1.22.22 | `npm install -g yarn` |
| Docker Desktop | Latest | https://docker.com |
| Compact Compiler | 0.31.0 | https://github.com/midnightntwrk/compact/releases |
| 1AM Wallet | Latest | Chrome Web Store |

### Install the Compact Compiler (Windows)

1. Go to: https://github.com/midnightntwrk/compact/releases
2. Download the Windows release for version 0.31.0
3. Extract to `C:\compact`
4. Add `C:\compact` to your Windows system PATH
5. Restart your terminal
6. Verify: `compact --version` → `compact 0.31.0`

### Install & Compile

```bash
# Install root dependencies
yarn install

# Compile the smart contract
yarn compile
# → generates contracts/managed/proofpass/

# Copy managed assets to frontend
yarn copy:managed
```

3. Paste the recruiter's contract address

5. Click **Generate Zero-Knowledge Proof**
6. Approve in 1AM wallet
7. Proof is verified on-chain ✅

## 🛡️ Smart Contract — Key Design Decisions

### Why `Uint<32>` scaled by 10 for CGPA?

Compact's `Uint<N>` types are integers. CGPA like `8.47` is stored as `84` (× 10). The circuit checks `creds.cgpa >= min_cgpa` using integer comparison.

### Why `admin_public_key` uses a domain separator?

```compact
persistentHash<Vector<2, Bytes<32>>>([pad(32, "proofpass:admin:v1"), sk])
```

The domain separator string `"proofpass:admin:v1"` prevents hash collisions if the same key bytes are used in different contexts in the future.

### Why nullifiers prevent identity disclosure

When a student proves eligibility, `make_nullifier(student_id)` produces a 32-byte hash. This hash is public. But because `student_id` is private (it's a witness), no one can reverse the nullifier to identify the student.

### Integer type-widening rule

Any arithmetic on `Uint<N>` widens the type. Always cast back:
```compact
// Correct:
total_verified = disclose((total_verified + 1) as Uint<32>);
```
