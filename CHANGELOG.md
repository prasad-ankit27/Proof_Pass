# Changelog

All notable changes to the ProofPass project will be documented in this file.

## [1.0.0] - 2026-09-22

### Added
- Compact smart contract with Zero-Knowledge credential verification circuits
- Private witness validation for student GPA, graduation year, and major
- Nullifier set preventing double-claims without revealing student identity
- React 18 + Vite frontend with Midnight Lace wallet integration
- Dynamic dark glassmorphism UI with Tailwind/CSS styling
- Docker Compose configuration for local Midnight network testing
- Complete Vitest unit and integration test suite
- Automated deployment scripts for Midnight Preproduction network
- Comprehensive README and Midnight Master Guide
