# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in ProofPass or its Compact smart contracts, please DO NOT open a public issue.

Instead, please send an advisory email directly to:
`indu6230@gmail.com`

Please include:
- A description of the issue and potential impact
- Detailed reproduction steps or Proof of Concept (PoC)
- Any proposed remediation

We take zero-knowledge circuit security and privacy seriously and will respond promptly to security reports.
